# 1-NLP Preprocessing

## 1. Packages

| package名     | 解释                                                                       |
| ------------ | ------------------------------------------------------------------------ |
| jieba        | 中文分词工具                                                                   |
| NLTK         | NLP通用工具, 包括分词（tokenizer），词根还原（lemmatization）， 词打标（tagging）， stopwords等功能 |
| spacy        | 多语种分词工具                                                                  |
| transformers | LLM，MLLM等语言视觉大模型库，以及对应的语义模型的autotokenizer (从单词到index映射)                  |
